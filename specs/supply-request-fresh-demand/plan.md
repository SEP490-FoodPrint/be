# Kế hoạch triển khai

1. Thêm bảng Prisma và migration lưu mốc suất theo khối và lượng nguyên liệu chuyển từ Đợt 1.
2. Tính nhu cầu theo thực đơn ngày, công thức khối và suất theo đợt trong mô-đun yêu cầu nhập hàng. Thêm endpoint đọc dữ liệu theo phạm vi trường.
3. Lưu mốc cùng giao dịch tạo đơn nhập tươi. Tích hợp kết quả API vào bảng tạo yêu cầu nhập hàng.
4. Chạy kiểm tra Spec Gate, kiểu dữ liệu, build và các bài kiểm thử nhu cầu và tạo đơn.
