# Inspection and retained-sample photos

Each delivery inspection decision and retained sample may contain one optional JPEG or PNG photo, captured on a device or selected from existing files. Save the photo together with the decision or sample, associate it with the responsible record, and permit authorized school users to see it later. Existing records and photo-free requests remain supported. Reject invalid or oversized files. Preserve the current authorization, transactional state changes and idempotency rules.
